# 11 Definitions and Glossary

[← Back to Index](index.md)

## Core Concepts

### Automation Blindness
The psychological tendency to trust AI-generated output without critical analysis because the output is professionally formatted and generally reliable.

### Brownfield Development
Updating a feature or specification for an existing piece of code. In SDD, this requires updating the spec *before* updating the code.

### Convergence
The process of iteratively comparing the implementation against the specification and plan, and fixing discrepancies until they are identical.

### Human-First Breakdown
The act of analyzing and decomposing requirements by hand before involving an AI, ensuring the developer remains the primary architect of the solution.

## Spec Kit Terminology

### Constitution
The global set of principles and standards for a project that guide all AI-generated output.

### Golden Path
The ideal sequence of SDD commands: `/speckit.specify` -> `/speckit.plan` -> `/speckit.tasks` -> `/speckit.implement` -> `/speckit.converge`.

### Presets
Customizable templates that override the default behavior of Spec Kit commands to enforce organizational or domain-specific standards.

### Spec-Driven Development (SDD)
A methodology where specifications are treated as executable artifacts that generate and validate implementation, rather than just documentation.
