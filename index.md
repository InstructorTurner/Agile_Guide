# Welcome to the Junior Developer Workflow Reference Guide

This guide is designed to help junior developers navigate the most common industry best practices for software development workflows.

## 🚀 Suggested Learning Path

If you aren't sure where to start, we recommend the following order:

1.  **[Agile Reference Guide](/agile_reference_guide/)** - Understand the philosophy and mindset of Agile.
2.  **[Scrum Reference Guide](/scrum_reference_guide/)** - Learn the most popular framework for implementing Agile.
3.  **[Git Reference Guide](/git_reference_guide/)** - Master the essential tools for version control and collaboration.
4.  **[Kanban Reference Guide](/kanban_reference_guide/)** - Learn how to manage flow and visualize work.
5.  **[Extreme Programming (XP) Guide](/extreme_programming_guide/)** - Dive into high-discipline engineering practices.

## How to Use This Guide
Each section is organized numerically. We recommend reading them in order to build a solid foundation before diving into advanced topics.
