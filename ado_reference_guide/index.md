# 🛠️ Azure DevOps (ADO) Reference Guide

Welcome to the ADO guide! While the Scrum Reference Guide teaches you the *philosophy* of how we work, this guide focuses on the *tool* we use to execute it. 

Azure DevOps is our central hub for planning, tracking, and coding. For junior developers, the most important areas are **Boards** (where we plan) and **Repos** (where we code).
