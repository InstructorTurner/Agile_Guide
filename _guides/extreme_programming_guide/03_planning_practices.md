# 🗓️ 03: Planning Practices - Aligning Value and Effort

**Goal:** To ensure the team is building the highest-value features with the least amount of waste.

## 🧩 User Stories (XP Style)
In XP, a User Story is not a requirement; it is a **promise for a conversation**.

**The Focus:** 
- **Business Value:** What does the user actually get?
- **Conversational Detail:** The details are hashed out between the developer and the Product Owner *during* the sprint, not months before.

## 🎮 The Planning Game
A collaborative process where the "Customer" (PO) and "Developers" negotiate the scope.

| Role | Contribution | Focus |
| :--- | :--- | :--- |
| **Product Owner** | Defines Value | "What is the most important thing to build next?" |
| **Developers** | Defines Cost | "How much effort will this realistically take?" |

**✅ Best Practice:** Use relative estimation (Story Points) to avoid the trap of precise-but-wrong hour estimates.

## 📉 Small Release Planning
Instead of a 12-month roadmap, XP plans in small, iterative versions.

**The Strategy:**
1. Identify the most valuable features.
2. Identify the highest-risk technical challenges.
3. Build those first to "de-risk" the project early.
