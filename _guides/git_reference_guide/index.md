# 🛠️ Git Best Practices Reference Guide

Welcome! This handbook is designed as a quick-reference guide for team members to manage source code collaboratively. It focuses on high-frequency integration, reducing merge friction, and embracing collective code ownership.

**💡 How to use this guide:**
*   **Quick Reference:** Use the specific guide for the task at hand (e.g., `02_the_pull_request_process.md` when opening a PR).
*   **Learning:** Read the foundational documents (`00_git_workflow_overview.md` and `01_branching_strategy.md`) first to understand our integration philosophy.
*   **Core Principles:** Pay special attention to the sections on **Short-Lived Branches** and **Vertical Slicing** to avoid "Merge Hell."
