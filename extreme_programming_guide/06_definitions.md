# Definitions

## XP Glossary

- **TDD (Test-Driven Development)**: A process where tests are written before the actual code.
- **Pair Programming**: Two developers sharing one screen to write code together.
- **Refactoring**: Cleaning up code without changing what it does.
- **YAGNI (You Ain't Gonna Need It)**: A principle of avoiding adding functionality until it is actually necessary.
- **CI (Continuous Integration)**: Frequently merging code into a shared repository to find errors quickly.
- **Collective Ownership**: The idea that everyone is responsible for all the code.
- **The Planning Game**: The collaborative effort between the business (Customer/PO) and the technical team to plan the release.
- **Sustainable Pace**: Working at a speed that can be maintained without burnout.
- **Whole Team**: Ensuring all necessary skills and decision-makers are integrated into the team.
