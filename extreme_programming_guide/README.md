# Extreme Programming (XP) Guide

This guide provides a broad, shallow dive into the practices of Extreme Programming (XP). While our team utilizes Scrum, XP offers a set of high-impact engineering and team practices that complement the Scrum framework.

The goal of this guide is to help junior developers understand Agile principles through the lens of XP and adopt useful practices to improve code quality and team collaboration.

## Guide Structure
- **00_xp_overview.md**: Philosophy and Core Values
- **01_engineering_practices.md**: TDD, Pair Programming, Refactoring, and Simple Design
- **02_delivery_practices.md**: CI, Small Releases, and Collective Ownership
- **03_planning_practices.md**: User Stories and the Planning Game
- **04_team_practices.md**: Whole Team, Sustainable Pace, and Coding Standards
- **05_scrum_integration.md**: Applying XP within Scrum
- **06_definitions.md**: XP Glossary
