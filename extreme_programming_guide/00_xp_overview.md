# XP Overview

Extreme Programming (XP) is an agile software development framework designed to improve software quality and responsiveness to changing customer requirements.

## The Philosophy
XP takes beneficial software engineering practices to "extreme" levels:
- If code reviews are good, we do them all the time (Pair Programming).
- If testing is good, we test all the time (TDD).
- If integration is good, we integrate all the time (CI).

## Core Values
1. **Communication**: Frequent, face-to-face interaction to avoid misunderstandings.
2. **Simplicity**: Doing the simplest thing that could possibly work.
3. **Feedback**: Rapid feedback loops from the system (tests), the customer, and the team.
4. **Courage**: The willingness to refactor, throw away code, and speak truthfully about progress.
5. **Respect**: Valuing the contribution of every team member.

## XP in a Scrum World
While Scrum provides the *management* framework (Sprints, Roles, Ceremonies), XP provides the *technical* framework. Think of XP as the "how" of building the increment that Scrum manages.
